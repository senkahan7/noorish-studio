🎬
Video Strategy
  • Poster images load first, video deferred until IntersectionObserver fires
  • Videos served in WebM + MP4 fallback, compressed to ≤3MB each
  • Hero reel: autoplay muted loop, max 720p, preload="none"
  • Filmstrip clips: preload first 2 frames only (metadata)
  • Consider Cloudinary or Cloudflare Stream for adaptive HLS
🧊
WebGL Budget
  • Single shared WebGL context (R3F Canvas, not per-section)
  • Bokeh particles: ≤500 instances using InstancedMesh
  • Film frame scene: max 8 plane geometries, shared material
  • Suspend all R3F scenes off-screen using
  • DREI's useIntersect to pause renders outside viewport
🖼️
Image Strategy
  • All gallery images: WebP format, 1× and 2× srcset
  • Native loading="lazy" + GSAP reveal after load fires
  • Masonry images: fixed aspect ratios to prevent layout shift (CLS 0)
  • LCP image (hero reel poster): preload link in <head>, eager load
  • LQIP (Low Quality Image Placeholders) for gallery tiles
⚡
JS Bundle
  • Code-split by route; R3F components lazy-loaded with Suspense
  • GSAP: import only used plugins (no full bundle)
  • Three.js: tree-shake via import from 'three/src/...'
  • Fonts: subset to Latin charset only, preconnect to Google Fonts
  • Target: LCP <2.5s, TBT <200ms, CLS = 0
🎞️
Animation Performance
  • Only animate transform + opacity — avoid paint-triggering properties
  • will-change: transform on cards that will 3D-transform
  • GSAP's force3D: true on all tween targets
  • Filmstrip scroll: use translate3d, not left/top
  • Kill all ScrollTriggers on component unmount (cleanup)
🏗️
Build + Infra
  • Vite: manual chunk splitting for three, gsap, r3f
  • Rollup visualizer to audit bundle on each build
  • Netlify: edge caching, HTTP/2 push for critical CSS
  • Environment flag: VITE_ENABLE_WEBGL=false for perf testing
  • Prerender critical HTML with vite-plugin-ssr for SEO
Mobile-first fallback strategy. All WebGL sections degrade gracefully. Target: iPhone 13+, Android mid-range (Snapdragon 778G equivalent).

Lightbox: full-screen modal with touch swipe navigation
Contact R3F
Floating film frames: disabled, replaced with CSS parallax divs

Form: full-width single column, larger tap targets (min 44px)
Submit button: standard — no custom cursor interaction
Global Rules
prefers-reduced-motion: all animations off except opacity fades
Lenis: disabled on iOS Safari ≤ 15 (native momentum scroll used)
Font sizes scale with clamp() — no overflow on small screens
detect-gpu hook: sets a React context WEBGL_ENABLED globally
Recommended implementation order. Each phase should be shippable independently.

Foundation (Days 1–3)
Vite + React + Tailwind setup with custom CSS variables (--gold, --dark, --grain)
Lenis smooth scroll installed and wired to GSAP ScrollTrigger via raf loop
Typography system — choose display font (Syne / Neue Montreal / Editorial New), install via Fontsource
Custom cursor component — global div following mouse, toggling states on .hoverable elements
Film grain overlay — CSS pseudo-element + JS flicker, applied globally
Page loader — film countdown animation (3-2-1), curtain wipe, then sets a loaded state
2
Hero Section (Days 4–6)
R3F canvas setup with bokeh particle system (InstancedMesh + shader material)
Hero text animation — GSAP SplitText stagger + clip-path reveal sequence
Muted video background — deferred load with poster fallback
Nav component — sticky with scroll-triggered glass morphism
3
Reel + Services (Days 7–11)
Horizontal filmstrip — GSAP pin + horizontal translate, velocity scrub, sprocket SVG decoration
Video clip previews — IntersectionObserver load, hover play/pause logic
Services card stack — CSS 3D perspective setup, ScrollTrigger for card reveal sequence
SVG icon draw animations — strokeDashoffset per service, triggered on card enter
4

Masonry gallery — CSS columns, category filter with GSAP Flip, lazy image loading

Cross-browser QA — Safari 16+, Chrome, Firefox, iOS Safari, Android Chrome
